01
Terminal Console
The whole home rendered as a live terminal session. Posts are command output (> cat post_001), nav is a file tree, everything prefixed with prompts. Maximum cohesion with the boot.
seeker@sin.city:~$ ls ~/feed
> post_001  post_002  post_003
seeker@sin.city:~$ cat post_001
┌ @v4xd [ADMIN] · 2d ago ────────
│ منورة نايمة
│ [img] rig.png
└ ♥ 12  ⌘ save  ✎ 3
seeker@sin.city:~$ _
